# Pet Care - Database

This folder contains SQL scripts for the Pet Care project.

## Sprint 3 Tables

- **medical_notes** - Stores medical notes for pets (US12, US13, US14)
- **reminders** - Stores user reminders for pet care tasks (US15)
- **tips** - Stores pet care tips and articles (US16, US17)

## How to run

1. Open MySQL Workbench
2. Connect to your local server
3. Open `sprint3.sql`
4. Press Ctrl+Shift+Enter to run

## Database
- Database name: `CLASS_DB`
- Connection: localhost
